# Tirthesh Gutte — Personal Portfolio

A responsive one-page portfolio built with HTML, CSS, and a small amount of JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design and styling
- `script.js` — mobile navigation toggle

## Run locally
Open `index.html` in your browser. You can also use the VS Code Live Server extension.

## Customize
1. Update the introduction, bio, skills, and project descriptions in `index.html`.
2. Replace sample project links with the correct repositories or live demos.
3. Adjust colors and layout in `styles.css` if desired.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `personal-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and open the URL shown in the Pages section. It usually looks like `https://YOUR-USERNAME.github.io/personal-portfolio/`.
7. Test the live page, then submit the live URL to the internship dashboard.

## Submission
Use your real GitHub repository URL or deployed GitHub Pages URL. Do not submit the example URL before deployment.
